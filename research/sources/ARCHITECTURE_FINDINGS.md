# Architecture Findings

1. Intelligence should not equal execution. LLM analysis can propose or interpret while deterministic software enforces hard risk and execution constraints.
2. Multi-timeframe analysis should preserve relationships between context, setup, trigger and invalidation.
3. Adversarial review can challenge an initial thesis.
4. Memory should be structured: decisions, state changes, outcomes and calibration rather than raw transcript dumps.
5. LLM confidence is not a calibrated probability and must not by itself determine position size.
6. Self-improvement needs versioning, reviewability and bounded invariants.

These findings guide the knowledge layer only and do not modify the autonomous agent.
