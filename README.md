# XAUUSD Trading Intelligence

Independent research and knowledge layer for the Autonomous XAUUSD Agent.

## Purpose

This repository is intentionally separate from the live agent. It will collect, evaluate, structure, and test trading knowledge before any integration with the agent.

## Research pillars

- Fable / Claude agentic behavior research and publicly available materials
- AI trading-agent repositories and architectures
- Classical technical analysis and price action
- Market structure, liquidity, auction and order-flow frameworks
- Quantitative, statistical and volatility methods
- Multi-timeframe analysis
- Macro, news and session context
- Trade management, risk and position sizing
- Execution quality and decision verification

## Principles

1. Do not hard-code a trading strategy.
2. Separate knowledge from claims and evidence.
3. Record source provenance.
4. Preserve competing interpretations and contradictions.
5. Do not treat backtests or GitHub claims as proof without context.
6. Build the knowledge layer first; integrate with the autonomous agent only after evaluation.
7. Keep the research reproducible and versioned.
