# Fable / Agentic Research

This file reserves a dedicated track for publicly available Fable-related material and other AI-agent research.

## Objective

Extract generalizable agent-engineering principles without importing Claude-specific environment behavior into the trading agent.

## Questions to investigate

- How does the system decompose objectives?
- How does it decide when to research?
- How does it use tools?
- How does it verify state changes and results?
- How does it handle uncertainty and conflicting evidence?
- How does it maintain state and memory?
- How does it recover from failed actions?
- Which behaviors come from prompts versus tools/harnesses?
- Which principles transfer cleanly to a trading research agent?

## Important boundary

Fable research is an input to the intelligence layer. It is not itself a trading strategy and must not determine market entries.
